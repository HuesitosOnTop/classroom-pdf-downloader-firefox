# classroom-pdf-downloader-firefox
Firefox extension for downloading every PDF linked on a Google Classroom assignment page.

## Features
- Works on Google Classroom assignment pages
- Finds PDF links on the page
- Downloads each file through Firefox's downloads API
- Includes a simple popup button for one-click use

## Install in Firefox
1. Open Firefox.
2. Go to `about:debugging`.
3. Click "This Firefox".
4. Click "Load Temporary Add-on".
5. Select the `manifest.json` file in this project.
6. Open a Google Classroom assignment page and click the extension's button.

## Notes
This first version targets the page structure shown in your screenshot and is built to be easy to extend for other Classroom pages.
